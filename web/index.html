Shufflepuck Café — Atari ST, 1989, rétro-ingénierie

Les images, les sons, la physique, l'intelligence des adversaires et leurs animations viennent du jeu d'origine, lus octet par octet sur les disquettes et dans le code 68000. La version spéciale (bouton ou touche F10) remplace les graphismes par des versions remasterisées. Ajoutez ?debug à l'adresse pour voir l'état du moteur.
